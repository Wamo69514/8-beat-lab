8 BEAT LAB v1.0 | ONBrake DJ Scratch Practice

4 SOUND LAB v6.1 から派生した「8拍 / 4音」の別アプリです。
1音につき2拍を割り当て、4音で8拍＝2小節のフレーズになります。
フレーズ行内の4つの箱を、左から各2拍ずつ進みます。
演奏中の音の箱を水色にし、箱下部のゲージが2拍で0%→100%に進みます。
中央の目盛り線が1拍の境目です。メトロノームは4/4を維持し、小節頭で高音が鳴ります。

「切替までの小節数」は従来どおり8～128小節。8小節なら2小節のフレーズを4回演奏後に次のActive行へ移ります。
BPM上昇タイミング「フレーズ」は2小節で1フレーズと計算します。
現行アプリの完全ランダム・半ランダム・固定、8種音＋連結ペア、音の抽選倍率、
Saveライブラリ（行ごと保存・行4に読み込み）、Reset、Pause、BPM上限などを継承します。

【GitHub Pages 公開方法】
4 SOUND LAB と分離するため、別の新規Publicリポジトリ（例：8-beat-lab）を作ります。
ZIP解凍後、フォルダの中の6ファイルを新規リポジトリ直下にアップロード。
Settings → Pages → Deploy from a branch → main / (root) → Save。
公開URLをSafariで開き、「ホーム画面に追加」。既存4 SOUND LABは上書きしないでください。

【保存と互換性】
このアプリのライブラリと入力は別のキーで保存され、4 SOUND LABを上書きしません。
旧4 SOUND LABでJSONバックアップを書き出し、本アプリの「バックアップを読み込む」で引き継ぐことはできます。
ただし移行した4音はここでは「各2拍」と解釈されます。両アプリ間の自動同期はしません。

【注意】
Web AudioはiOSでバックグラウンドになると停止・一時停止することがあります。
初回は画面を表示した状態でStartを押してください。実機iOSの音声再生は未検証です。
